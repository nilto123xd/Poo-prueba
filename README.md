## Cómo ejecutar
1. Descargar el proyecto: en GitHub, **Code > Download ZIP**, y descomprimirlo.
2. En NetBeans: **File > Open Project** y elegir la carpeta (es un proyecto Maven, Java 17 o superior).
3. En `Source Packages > Ejecucion`, clic derecho en la clase ejecutora > **Run File**.

## Estructura
- `src/main/java/Clases`: las clases del problema.
- `src/main/java/Ejecucion`: la clase con el `main`.
